## 🎬 How to Use These Assets

Each feature file is structured into three self-contained production phases:

1. **Technical Breakdown & Word-for-Word Narration Script:**
   - Detailed plain-English software engineering explanation.
   - 90-second voiceover narration script with precise timestamps `[0:00 - 0:15]`, audio tone guidance, visual cues, and sound design (SFX) specifications.
   - Paste the narration text directly into AI Voice generators (e.g., ElevenLabs, Play.ht, OpenAI TTS). Recommended voice profile: Deep, articulate documentary narrator (e.g., ElevenLabs "Adam", "Marcus", or "George").

2. **Step-by-Step Visual Analogy & Mapping Table:**
   - Transforms abstract code routines (combinatorial state spaces, Cartesian product matrices, parametric Bezier coordinates) into intuitive physical metaphors.
   - Includes a 1-to-1 mapping table translating code entities into real-world visual subjects.

3. **Frame-by-Frame AI Text-to-Video Prompts:**
   - 6 to 7 modular video shots per feature (6 to 8 seconds each), perfectly matching the narration timing.
   - Formatted for direct copy-and-paste into text-to-video AI platforms:
     - **OpenAI Sora / Runway Gen-3 Alpha:** Paste the prompt directly into the text prompt box with Camera Motion parameters set to subtle dolly/orbit.
     - **Luma Dream Machine:** Paste the prompt with `motion: low` for smooth cinematic tracking.
     - **Kling AI / Haiper:** Paste prompt with `Professional mode` and `1080p / 4K upscale`.

All five repositories from the [`chiokebuckley-art`](https://github.com/chiokebuckley-art) ecosystem are cloned and intact in the local workspace:

3. **`engineering-quest/`**: Massive multi-subject simulation quest platform encompassing Reality Lab (Arduino UNO R3 DC nodal circuit solver), Count Lab (Hi-Lo probability engine), and Equation Plaza (connected math board game).
4. **`element-city/`**: City-building chemistry simulation game driven by element synthesis and chemical reaction equations.
5. **`wordraiders/`**: Comprehensive English linguistics and literacy platform featuring StoryForge screenplay engine, phonics decoders, and syntax arcades.
